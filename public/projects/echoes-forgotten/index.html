🛡️ Hex Tower Defense

A Strategic Mobile Tower Defense with Decoupled Architecture

📖 Project Overview

Hex Tower Defense is a 3D strategic mobile game set in a world where creatures have been mutated by parasitic crystals. Players harness the power of specialized Crystal Towers to repel waves of infected monstrosities.

Core Gameplay Mechanics:

  • Loadout System: Players strategically select 5 offensive towers to bring into battle.
  • Maze Building: Utilize a low-cost Wall Tower to construct intricate mazes, manipulating enemy pathing. Note: The wall cost scales dynamically with each placement to balance the economy.
  • Tower Fusion: Combine basic towers to evolve them into powerful, specialized variants.
  • Objective: Protect the Core Base at all costs by neutralizing all incoming threats.

🏗️ System Architecture & Engineering

The core philosophy of this project is High Scalability and Engine Independence.

1. Decoupled Logic/View Architecture

Inspired by a rigorous industry technical test, this system is designed to be Engine-Agnostic. By separating pure C# game logic from the Unity-specific View layer:

  • Independence: The system can be ported to other engines or even a Console Application with minimal effort.
  • Maintainability: Logic resides in pure C# classes, making it easier to debug and unit test without Unity’s overhead.
  • Flexibility: Switching UI frameworks or visual representations doesn’t require rewriting core mechanics.

2. Applied Design Principles

  • SOLID & Clean Code: Strict adherence to modular design to ensure the codebase remains readable and extensible for future features.
  • Data-Driven Design: Using ScriptableObjects to define tower stats and enemy waves, allowing for rapid balancing without modifying code.

⚡ Technical Highlights & Optimization

1. Advanced Pathfinding System

To ensure smooth performance on mobile devices, I implemented a hybrid pathfinding solution:

  • A (A-Star) Algorithm:* Used for real-time enemy navigation from spawn points to the Core Base. I chose A* for its efficiency, focusing calculations on nodes closer to the target to save CPU cycles.
  • BFS (Breadth-First Search) Validation: After every tower placement, a BFS scan runs from the target outwards. This ensures no enemies are completely trapped (blocking bug prevention), maintaining the integrity of the maze-building mechanic.

2. High-Performance Mobile Optimization

  • Object Pooling: Implemented for projectiles, enemies, and VFX to eliminate the high cost of Instantiate and Destroy calls, preventing frame drops during intense waves.
  • Observer Pattern (Event System): Used an event-driven approach for HP updates and UI triggers, reducing direct dependencies between objects and avoiding costly Update() checks.
  • Efficient Grid Management: A custom hex-grid coordinate system optimized for rapid lookup and pathfinding calculations.

🚀 Future Roadmap

  • AWS Integration: Implementing AWS Cognito for secure user authentication and DynamoDB for cloud-based player progress and global leaderboards.
  • Advanced Meta-Progression: Adding a persistent skill tree and tower upgrade system.
  • Multiplayer Elements: Exploring asynchronous Co-op or PvP modes via cloud services.
